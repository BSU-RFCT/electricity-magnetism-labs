# Лабораторные работы по электричеству и магнетизму

Отчёты по лабораторным работам по курсу физики (электричество и магнетизм), БГУ.

Отчёты написаны на LaTeX, скомпилированные PDF приложены рядом.

## Содержимое

| Работа | Тема |
|---|---|
| `5` | Зависимость сопротивления металлов и полупроводников от температуры |
| `10` | Термоэлектронная эмиссия. ВАХ вакуумного диода. Удельный заряд и работа выхода электрона |
| `13` | Магнитное поле соленоида и колец Гельмгольца |
| `14` | Измерение электрических сопротивлений |

`ref.tex` / `ref.pdf` — реферат на тему "Парамагнетизм".

## Компиляция

```bash
xelatex 5.tex
```
